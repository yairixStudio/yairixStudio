# YAIRIX Studio

**Building privacy-first AI tools, macOS utilities and web apps.**

🌐 [yairix.com](https://yairix.com)

## 🤖 AI Tools

- **[claude-code-steroids](https://github.com/yairixStudio/claude-code-steroids)** — right-click any folder to open it in Claude Code, or launch 9 parallel sessions in a 3×3 grid.
- **[404fix](https://github.com/yairixStudio/404fix)** — WordPress plugin that turns 404 pages into AI-generated landing pages. BYOK: OpenAI, Claude, Gemini or self-hosted LLMs.

## 🍎 macOS Tools

- **[whoRU](https://github.com/yairixStudio/whoRU)** — know who is really asking before you click Allow on a permission dialog.
- **[shutlid](https://github.com/yairixStudio/shutlid)** — keep your MacBook awake with the lid closed, no external display needed.

## 🌐 Web Projects

- **[zrp-il-art](https://github.com/yairixStudio/zrp-il-art)** — production static site for the Zielinski & Rozen art galleries, Tel Aviv, with responsive AVIF + WebP image delivery.
- **[clockwize](https://github.com/yairixStudio/clockwize)** — freelancer time-tracking and client/project management (React + Node.js + SQLite).
- **[zna26](https://github.com/yairixStudio/zna26)** — installable PWA fan guide for the ZNA Gathering 2026 festival.
- **[dira-behanaha-9218](https://github.com/yairixStudio/dira-behanaha-9218)** — Hebrew data dashboard for Israel's 2026 subsidized-housing lottery.

## 🧩 Chrome Extensions

Free, privacy-first Manifest V3 extensions — everything runs locally in your browser, no uploads, no tracking:

| Extension | What it does |
|---|---|
| [PDF Editor](https://github.com/yairixStudio/YAIRIX-PDF-Editor) | Merge, split & reorder PDF pages — 100% offline |
| [Element to LLM](https://github.com/yairixStudio/YAIRIX-Element-to-LLM) | Turn any page element into LLM-ready context for AI coding tools |
| [Photo Converter](https://github.com/yairixStudio/YAIRIX-Photo-Converter) | Batch-convert PNG/JPG to WebP or AVIF, fully offline |
| [Photo Optimizer](https://github.com/yairixStudio/YAIRIX-Photo-Optimizer) | Batch-compress JPG & PNG with adjustable quality + ZIP download |
| [Quick QR](https://github.com/yairixStudio/YAIRIX-Quick-QR) | Offline QR code generator — create, customize, download & share |
| [Localhost Side Panel](https://github.com/yairixStudio/YAIRIX-Localhost-Side-Panel) | Preview your dev server in Chrome's side panel while you browse |
| [Cache Cleaner](https://github.com/yairixStudio/YAIRIX-Cache-Cleaner) | Clear cache, cookies & site data for one site or the whole browser |
| [Auto Scroll](https://github.com/yairixStudio/YAIRIX-Auto-Scroll) | Hands-free scrolling with click-anchor control and variable speed |
| [Background Remover](https://github.com/yairixStudio/YAIRIX-Background-Remover) | One-click AI background removal (bring your own ClipDrop key) |
| [Wix Edit Helper](https://github.com/yairixStudio/YAIRIX-Wix-Edit-Helper) | Jump from any live Wix page straight to its dashboard editor |
| [Web App Popup](https://github.com/yairixStudio/YAIRIX-Web-App-Popup) | Template that turns any web app into a toolbar popup extension |
